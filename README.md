# 🌐 GPWK-College-Website
A responsive and user-friendly website designed for "Government Polytechnic for Women, Kandaghat (GPWK)". This project provides essential information about courses, departments, faculty, students services, and visitors with easy access to academic details, announcements, and contact information. Built using HTML, CSS, JavaScript, PHP and MySQL with a focus on clean UI and mobile responsiveness.

---

## 📌 Project Overview

The GPWK website serves as an online platform to showcase academic details, announcements, and resources for students, faculty, and visitors. The website includes sections like:

- 📚 Courses Offered
- 🎓 Student Corner
- 🧑‍🏫 Faculty & Staff 
- 🗓️ Announcements and Events  
- 📝 Admission Information  
- 📞 Contact Page

Built with clean UI, mobile responsiveness, and easy navigation in mind.

---

## 🛠️ Tech Stack

-  HTML5, CSS3, JavaScript, Bootstrap, PHP, MySQL  

---

## 🚀 Features

- Responsive layout for all devices  
- Clean and accessible navigation  
- Static or dynamic pages for departments and staff
- Visual Tour of College
- Contact Information
